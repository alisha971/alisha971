The SVGs are local assets; the expandable project details are native GitHub Markdown.
GitHub's renderer controls the styling of <details>/<summary>, so those interactive parts
cannot be given an arbitrary CSS border. The SVG section dividers and header provide the
custom visual treatment around them.
